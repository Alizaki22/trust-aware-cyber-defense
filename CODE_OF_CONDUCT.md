# Code of Conduct

## Purpose

This code of conduct applies to all contributors — human and AI — working on the Fine-Tuned Multi-Agent AI for Cyber Defense project. It establishes expectations for respectful, honest, and collaborative participation appropriate for a university academic environment.

## Our Standards

### Expected Behavior

- **Respectful communication.** Treat all team members with respect, regardless of experience level or role.
- **Constructive feedback.** Provide helpful, specific feedback on code, documentation, and ideas.
- **Honest reporting.** Report results, progress, and difficulties honestly. Do not claim work was done that was not actually performed.
- **Academic integrity.** Do not fabricate research results, citations, datasets, or experimental outcomes.
- **Collaborative learning.** Share knowledge and help team members understand the complete system.
- **Responsible use of AI tools.** When using AI coding agents, follow the rules in `AGENTS.md` and verify generated code actually works.

### Unacceptable Behavior

- Disrespectful, dismissive, or hostile communication.
- Fabricating research, data, test results, or citations.
- Claiming credit for work not actually performed.
- Pushing directly to `main` or bypassing the agreed review process.
- Implementing offensive security capabilities or actions against real systems.
- Silently changing the project architecture or scope without team approval.
- Using the project to access or attack unauthorized systems.

## Scope

This code of conduct applies to all project interactions: code reviews, pull requests, issues, documentation, team meetings, and communications about the project.

## Enforcement

Violations of this code of conduct should be discussed within the team. Repeated or serious violations should be escalated to the course instructor or academic supervisor.

## Academic Context

This is a university project. All participants are expected to follow their institution's academic integrity policies in addition to this code of conduct. The project must comply with all applicable university policies regarding coursework, collaboration, and the use of AI tools.

## Attribution

This Code of Conduct is adapted for the specific needs of a small, academic student team. It draws on general principles common to open-source codes of conduct, tailored for a learning-first project context.
